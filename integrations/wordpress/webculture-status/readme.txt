=== Web Culture status ===
Stable tag: 1.0.0
License: GPL-2.0-or-later

Lets your hosting provider (Web Culture) pause this site with a suspension page for unpaid hosting, and switch it back on, from EventureOS.

== Setup ==
1. Upload and activate the plugin.
2. Settings → Web Culture status: paste the site key from EventureOS → Hosting.

Checks every 10 minutes. If EventureOS can't be reached, the site keeps its last state. Logged-in administrators always see the site.
